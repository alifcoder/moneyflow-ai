# MoneyFlow AI

MoneyFlow AI is a portfolio-focused personal finance application for tracking income, expenses, reference data, and reports through a simple Laravel and Inertia architecture.

## Stack

- Laravel 13
- PHP 8.5
- PostgreSQL
- Inertia.js 3
- Vue 3
- Tailwind CSS

## Current Scope

This repository is currently prepared with the base project structure only. Business CRUD, transaction workflows, reports, and role wiring are intentionally deferred to later implementation tasks.
