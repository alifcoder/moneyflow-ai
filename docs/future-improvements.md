# Future Improvements

This project intentionally keeps accounting and reporting simple. The following improvements are good candidates for future work after the current portfolio scope is stable.

## Product Features

- Recurring transactions.
- Transaction attachments.
- Budget limits by category.
- Import from CSV.
- Export reports to CSV or PDF.
- Saved report filters.
- Multi-currency exchange-rate conversion.
- Cashbox transfer transactions.
- Category color customization.

## Reporting

- Date comparison periods.
- Running balances.
- Cashflow projections.
- Category trend charts.
- Per-currency totals when reports include mixed currencies.

## Engineering

- Add a CI workflow for formatting, tests, and frontend build.
- Add browser-level smoke tests for critical flows.
- Add visual regression checks for mobile report charts.
- Add stricter static analysis once the domain stabilizes.
- Add database indexes review after realistic seed data exists.

## UX

- Add accessible chart summaries.
- Add keyboard-friendly bulk filter reset.
