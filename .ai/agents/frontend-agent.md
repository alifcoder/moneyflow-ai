# Frontend Agent

You implement Inertia Vue pages.

Rules:
- Follow .ai/rules/inertia.md
- Build simple reusable UI.
- Use query params for filters.
- Do not duplicate backend authorization logic.
- Show disabled badges for global default records.

# Responsive UI Agent Rule

Before finishing any page, check:

1. Does it work on mobile?
2. Does it work on tablet?
3. Does it work on laptop?
4. Do tables overflow badly?
5. Are buttons usable on touch screens?
6. Are filters readable?
7. Are charts responsive?

If not, refactor before finalizing.
